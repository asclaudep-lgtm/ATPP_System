# Быстрый старт

## 🚀 Запуск за 3 шага

### 1. Установите зависимости
```bash
pip install -r requirements.txt
```

### 2. Запустите приложение
```bash
python main.py
```

### 3. Войдите в систему
- Логин: `admin`
- Пароль: `admin`

## 📋 Основные возможности

### Создание технологического процесса
1. Меню **Файл** → **Новый ТП**
2. Выберите изделие или создайте новое
3. Выберите режим проектирования:
   - **Диалоговый** - ручное заполнение
   - **Полуавтоматический** - система предлагает варианты
   - **Автоматический** - полная автоматизация

### Добавление операций
1. Откройте ТП
2. Нажмите **Добавить операцию**
3. Заполните параметры:
   - Номер (005, 010, 015...)
   - Наименование
   - Оборудование
   - Профессия и разряд

### Расчёт норм
- **Материальное нормирование**: Инструменты → Материальное нормирование
- **Трудовое нормирование**: Инструменты → Трудовое нормирование
- **Себестоимость**: Инструменты → Расчёт себестоимости

### Генерация документов
1. Откройте ТП
2. Меню **Документы** → **Генерировать комплект**
3. Выберите формат (Excel, PDF, Word)

## 📚 Справочники

Заполните справочники перед началом работы:
- **Материалы**: Справочники → Материалы
- **Оборудование**: Справочники → Оборудование
- **Инструмент**: Справочники → Инструмент
- **Профессии**: Справочники → Профессии и разряды

## ⚙️ Настройки

Настройте параметры расчётов:
- Сервис → Настройки системы
- Коэффициенты расхода материалов
- Процент отчислений
- Цеховые и общезаводские расходы

## 🔧 Решение проблем

### Приложение не запускается
```bash
# Проверьте версию Python (должна быть 3.11+)
python --version

# Переустановите зависимости
pip install --upgrade -r requirements.txt
```

### Ошибка базы данных
Удалите файл `data/atpp.db` и перезапустите приложение

### Не отображаются шрифты
Установите шрифты Arial или Segoe UI

## 💡 Советы

1. **Используйте горячие клавиши**:
   - `Ctrl+N` - Новый ТП
   - `Ctrl+S` - Сохранить
   - `Ctrl+F` - Поиск
   - `F1` - Справка

2. **Создавайте резервные копии**:
   - Файл → Резервная копия БД

3. **Используйте шаблоны**:
   - Создайте типовые ТП для повторного использования

4. **Проверяйте ТП перед утверждением**:
   - Инструменты → Проверка ТП

## 🎯 Типовой рабочий процесс

1. Создать изделие (обозначение, материал, габариты)
2. Создать ТП для изделия
3. Добавить операции
4. Добавить переходы для каждой операции
5. Рассчитать нормы времени
6. Рассчитать расход материалов
7. Рассчитать себестоимость
8. Проверить ТП
9. Утвердить ТП
10. Сгенерировать документы

# Локализация

Каркас локализации Qt-приложения. Для полного перевода UI на другой язык:

## Шаги

1. Прогнать `pylupdate6` по проекту, чтобы собрать строки для перевода:

   ```bash
   pylupdate6 ../../ui/**/*.py ../../modules/**/*.py -ts atpp_en.ts
   ```

2. Открыть `atpp_en.ts` в Qt Linguist, перевести строки.

3. Скомпилировать в .qm:

   ```bash
   lrelease atpp_en.ts -qm atpp_en.qm
   ```

4. В приложении выбрать в меню *Сервис → Настройки внешнего вида* язык
   «English» — после перезапуска интерфейс будет на выбранном языке.

## Текущее состояние

- `launcher.py` загружает QTranslator из `resources/i18n/atpp_<lang>.qm`,
  если файл существует и `language != 'ru'`.
- В коде ещё не все строки обёрнуты в `self.tr(...)` — нужно вычитывать
  модули по мере появления в Linguist.
- Этот каталог сейчас пустой (нет готовых .qm), поэтому сменa языка в
  настройках не приведёт к видимым изменениям, но подготовка для перевода
  выполнена и ничего не сломается.

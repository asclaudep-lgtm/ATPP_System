# ATPP_System v7 — установка под Windows (оффлайн)

В архиве уже находятся все зависимости (~123 МБ wheel-файлов в папке
`wheels/`), интернет для установки не нужен.

## Что нужно один раз поставить

**Python 3.12** (64-bit) с сайта <https://www.python.org/downloads/>.
Во время установки обязательно поставьте галку **«Add Python to PATH»**.

Если Python ещё нет — поставьте, перезагрузите окно командной строки, и
только потом запускайте установку.

## Установка приложения

1. Распакуйте архив в удобную папку (например, `C:\ATPP_System`).
2. Перейдите в эту папку.
3. Дважды кликните **`install_windows.bat`**.
   - Скрипт сам создаст виртуальное окружение `.venv`.
   - Установит все зависимости из локальной папки `wheels/`.
   - Сообщит «УСПЕХ!» и попросит нажать любую клавишу.

Установка занимает ~2 минуты.

## Запуск приложения

Дважды кликните **`run_app.bat`**. Откроется окно входа в ATPP_System.

Логин/пароль по умолчанию (если БД создаётся с нуля):
```
admin / admin
```
(После первого входа смените пароль через меню «Пользователи».)

## Если что-то не работает

### «Python не найден в PATH»
Установите Python 3.12 заново, не забывая галку «Add Python to PATH».

### «Колёса в папке wheels\ могут не подойти»
Wheel-файлы собраны под Python **3.12** для Windows x64. Если у вас другая
версия Python, перекачайте wheel-ы или установите Python 3.12.

### «PyQt6 не запускается»
Скорее всего, не хватает DLL Visual C++ Redistributable. Скачайте и
поставьте «Microsoft Visual C++ Redistributable for Visual Studio 2015–2022»
(x64) с <https://aka.ms/vs/17/release/vc_redist.x64.exe>.

### Подключение к PostgreSQL вместо SQLite
Откройте файл `data/db.cfg.example`, скопируйте как `data/db.cfg`,
впишите параметры подключения к серверу PostgreSQL. Подробнее — в
`docs/postgresql_setup.md`.

## Структура

```
ATPP_System/
├── install_windows.bat   ← запустить один раз для установки
├── run_app.bat           ← запуск приложения
├── README_WINDOWS.md     ← этот файл
├── wheels/               ← оффлайн-зависимости (123 МБ, 29 файлов)
├── launcher.py           ← точка входа
├── requirements.txt
├── ui/                   ← интерфейс
├── modules/              ← бизнес-логика
├── database/             ← модели и менеджер БД
├── data/                 ← БД, эскизы, бэкапы (создаётся при первом запуске)
├── resources/            ← шаблон МТП УЗГА и другие ресурсы
├── docs/                 ← документация
├── tests/                ← автотесты
└── scripts/deploy/       ← скрипты развёртывания на сервер
```

## Обновление до новой версии

1. Скачайте новый архив.
2. Сохраните папку `data/` (там БД и эскизы).
3. Распакуйте новый архив в новую папку.
4. Скопируйте старую `data/` поверх новой.
5. Запустите `install_windows.bat`, потом `run_app.bat`.
6. БД мигрирует автоматически при первом запуске.

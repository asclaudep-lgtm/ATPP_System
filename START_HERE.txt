🔧 РЕШЕНИЕ ПРОБЛЕМ
═══════════════════════════════════════════════════════════════════════════════

Проблема: "python не является внутренней или внешней командой"
Решение:  Установите Python с https://www.python.org/downloads/
          При установке отметьте "Add Python to PATH"

Проблема: "No module named 'PyQt6'"
Решение:  pip install PyQt6

Проблема: Приложение не запускается
Решение:  1. Проверьте версию Python: python --version
          2. Переустановите зависимости: pip install --upgrade -r requirements.txt
          3. Удалите папку data/ и перезапустите

💡 ПОЛЕЗНЫЕ СОВЕТЫ
═══════════════════════════════════════════════════════════════════════════════

1. Создавайте резервные копии БД (Файл → Резервная копия БД)
2. Используйте горячие клавиши (Ctrl+N, Ctrl+S, Ctrl+F)
3. Заполните справочники перед началом работы
4. Проверяйте ТП перед утверждением (Инструменты → Проверка ТП)

# Инструкция по установке и запуску

## Требования
- Python 3.11 или выше
- pip (менеджер пакетов Python)

## Установка

### 1. Установка Python
Если Python не установлен, скачайте и установите с официального сайта:
https://www.python.org/downloads/

При установке обязательно отметьте "Add Python to PATH"

### 2. Создание виртуального окружения (рекомендуется)
```bash
python -m venv venv
```

### 3. Активация виртуального окружения

**Windows:**
```bash
venv\Scripts\activate
```

**Linux/Mac:**
```bash
source venv/bin/activate
```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

## Запуск приложения

```bash
python main.py
```

## Первый вход

При первом запуске используйте учётные данные по умолчанию:
- **Логин:** admin
- **Пароль:** admin

**ВАЖНО:** После первого входа рекомендуется сменить пароль администратора!

## Структура базы данных

При первом запуске автоматически создаётся база данных SQLite в папке `data/atpp.db`

База данных содержит:
- Пользователя admin
- Базовые справочники материалов
- Базовые справочники оборудования
- Базовые справочники профессий

## Настройка

Основные настройки находятся в файле `config.py`:
- Путь к базе данных
- Размеры окна
- Коэффициенты расчётов
- Пути к шаблонам и экспорту

## Использование PostgreSQL (опционально)

Для использования PostgreSQL вместо SQLite:

1. Установите PostgreSQL
2. Создайте базу данных
3. Установите переменную окружения:
```bash
set DATABASE_URL=postgresql://user:password@localhost/atpp_db
```

## Решение проблем

### Ошибка "No module named 'PyQt6'"
```bash
pip install PyQt6
```

### Ошибка "No module named 'sqlalchemy'"
```bash
pip install sqlalchemy
```

### Ошибка при запуске на Windows
Убедитесь что Python добавлен в PATH и используете правильную команду активации venv

### База данных не создаётся
Проверьте права доступа к папке `data/`

## Обновление

Для обновления зависимостей:
```bash
pip install --upgrade -r requirements.txt
```

## Техническая поддержка

При возникновении проблем обращайтесь к документации или в службу поддержки.

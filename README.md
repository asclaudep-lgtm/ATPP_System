# ATPP_System v5

Система автоматизации технологической подготовки производства (УЗГА-Инжиниринг).

## С чего начать

| Если Вы… | Откройте |
|---|---|
| хотите быстро установить и попробовать | **`УСТАНОВКА.md`** — единая пошаговая инструкция (часть A). |
| ставите систему в локальной сети | **`УСТАНОВКА.md`** — части B (сервер) и C (клиенты). |
| хотите общий обзор возможностей со скриншотами | **`ATPP_Presentation.pdf`** — презентация системы. |
| настраиваете резервные копии и восстановление | **`docs/backup_recovery_ru.md`**. |
| знакомитесь с модулем «Производство» | **`docs/production_ru.md`**. |

## Возможности

- Проектирование технологических процессов: операции, переходы, нормирование,
  расчёт Тшт/Тпз, расчёт себестоимости.
- Документация ГОСТ 3.1xxx: МК, МСК, МТП, ВО, ОК, КЭ — Excel/Word/PDF.
- Журнал регистрации ТП/МТП, дашборд полноты данных, audit-лог изменений.
- Workflow утверждения ТП с электронными подписями.
- **Модуль «Производство» (v5):** наряды, партии, маршруты по участкам,
  штрих-коды Code128, журнал событий, проблемы (нет материала / инструмента
  / вопрос по КД / оборудование / ОТК / прочее).
- Многопользовательская работа в локальной сети через PostgreSQL.
- Резервное копирование в трёх местах (сервер по расписанию + клиент при
  запуске + зеркало клиентского бэкапа на сервер).
- Семь ролей доступа: admin / technologist / engineer / master / worker /
  qc / user — с разграничением действий.

## Технологии

- Python 3.11+
- PyQt6 (GUI)
- SQLAlchemy 2.x + Alembic
- PostgreSQL 16 (LAN) или SQLite (локально)
- openpyxl, python-docx, reportlab — документы
- python-barcode + Pillow — штрих-коды
- bcrypt — хеширование паролей

## Запуск (после установки)

```bash
python main.py
```

Логин по умолчанию: `admin / admin` (сменить сразу после первого входа).

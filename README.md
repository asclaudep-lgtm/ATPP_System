# ATPP_System v10

Система автоматизации технологической подготовки производства (УЗГА-Инжиниринг).

## С чего начать

| Если Вы… | Откройте |
|---|---|
| хотите быстро установить и попробовать | **`УСТАНОВКА.md`** — единая пошаговая инструкция (часть A). |
| ставите систему в локальной сети | **`УСТАНОВКА.md`** — части B (сервер) и C (клиенты). |
| хотите общий обзор возможностей со скриншотами | **`ATPP_Presentation.pdf`** — презентация системы. |
| настраиваете резервные копии и восстановление | **`docs/backup_recovery_ru.md`**. |
| знакомитесь с модулем «Производство» | **`docs/production_ru.md`**. |

## Возможности

- **Проектирование ТП:** операции, переходы, нормирование, расчёт Тшт/Тпз, себестоимость.
- **Документация ГОСТ 3.1xxx:** МК, МСК, МТП, ВО — Excel/Word/PDF.
- **Производство:** наряды, партии, маршруты, штрих-коды Code128, фотофиксация.
- **Workflow:** утверждение ТП с электронными подписями, ECN.
- **Справочники:** материалы, оборудование, инструмент, профессии, оснастка.
- **Аналитика:** дашборд KPI, загрузка оборудования, Gantt-планировщик.
- **Интеграции:** CAD (STEP), 1С (XML/JSON), PDM, IoT (MQTT).
- **Веб-клиент:** FastAPI + Vue.js 3 SPA.
- **AI-ассистент:** подсказки операций ТП.
- 7 ролей доступа: admin / technologist / engineer / master / worker / qc / user.
- Резервное копирование (SQLite + PostgreSQL), Docker, CI.

## Технологии

- Python 3.11+
- PyQt6 (GUI)
- FastAPI + Vue.js 3 (веб-клиент)
- SQLAlchemy 2.x + Alembic
- PostgreSQL 16 (LAN) или SQLite (локально)
- openpyxl, python-docx, reportlab — документы
- python-barcode + Pillow — штрих-коды
- bcrypt + python-jose (JWT) — авторизация
- paho-mqtt — IoT
- Docker

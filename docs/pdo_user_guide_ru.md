# Модуль ПДО — руководство пользователя

ПДО (планово-диспетчерский отдел) управляет заказами на производство от
момента получения заявки до передачи в цех и закрытия.

---

## 1. Как открыть

- **Desktop:** меню «Сервис → Диспетчер ПДО» или «Сервис → Аналитика ПДО»
- **Веб:** вкладка «ПДО» в SPA (http://localhost:8000)

---

## 2. Процесс обработки заказа (7 статусов)

| Статус | Кто работает | Что делает |
|---|---|---|
| 📥 **Новый** | ПЭУ | Заказ создан, ожидает передачи в ОМТС |
| 📦 **ОМТС: проработка** | Снабжение | Проверка наличия материала, выпуск служебной записки (тип «У») |
| 🔧 **Тех.отдел: проверка** | Технолог | Проверка КД, определение материала, оценка возможности изготовления (+/−) |
| ✍ **Зам.Тех.Дир** | Руководитель | Утверждение, выпуск служебной записки на изготовление (тип «П») |
| ✅ **Утверждён** | ПЭУ | Заказ готов к созданию наряда |
| 🏭 **В цехе** | Мастер | Изготовление по наряд-заданию |
| 🔍 **ОТК** | Контроль | Приёмка, закрытие |

---

## 3. Создание заказа

1. Нажать **«+ Новый заказ»** (зелёная кнопка вверху)
2. Ввести обозначение изделия (автодополнение из справочника)
3. Заполнить: тип ВС, заказчик, объём работ
4. Добавить позиции номенклатуры (таблица: обозначение, наименование, кол-во)
5. Нажать **«Создать заказ»**

---

## 4. Канбан-доска

Заказы распределены по 7 колонкам (статусам).

- **Двойной клик** по карточке → детальная панель справа
- **Перетаскивание** (drag-and-drop) — схватите карточку и перетащите в нужную колонку
- **Поиск** — строка над канбаном фильтрует заказы по номеру, изделию, типу ВС
- **Пакетное перемещение** — выпадающий список «Пакетно: переместить в...» меняет статус всех видимых заказов

### Что показывают карточки

- Номер заказа и приоритет (звёзды)
- Обозначение изделия
- Тип ВС (если указан)
- Количество позиций номенклатуры с флагами +/− (возможно/невозможно)
- Служебные записки: У (указание ОМТС) и П (приказ Зам.Тех.Дир)
- Срок (красный — просрочен, оранжевый — сегодня)

---

## 5. Детальная панель (справа)

При клике на заказ показывает:

- **Информация:** номер, изделие, ВС, статус, количество, технолог, МТП
- **Номенклатура:** таблица позиций с КД, материалом, флагом возможности
- **Служебные записки:** тип (У/П), номер, отдел, содержание
- **История передач:** цепочка между отделами с датами

---

## 6. Действия по ролям

| Роль | Доступные действия |
|---|---|
| **ПЭУ / admin** | Создание заказа, экспорт Excel, пакетное перемещение |
| **ОМТС** | Кнопка «Начать проработку» → выпуск записки «У» |
| **Технолог** | Отметка КД, материала, feasibility (+/−) по каждой позиции |
| **Зам.Тех.Дир** | Кнопка «Утвердить» → выпуск записки «П» |
| **Мастер** | Принять заказ в цехе (создаётся WorkOrder) |
| **ОТК** | Закрыть заказ |

---

## 7. Аналитика ПДО

Меню «Сервис → Аналитика ПДО» открывает три вкладки:

- **Узкие места** — среднее время в каждом отделе, где заказы застревают
- **Застрявшие заказы** — какие заказы висят без движения >14 дней
- **График** — хронология этапов по каждому заказу

---

## 8. Экспорт

Кнопка **«📄 Экспорт Excel»** выгружает все заказы с полями:
номер, изделие, ВС, статус, количество, заказчик, позиций, записок, срок.

---

## 9. Горячие клавиши (F1)

Нажмите F1 в любом месте приложения для списка всех горячих клавиш.

---

## 10. Частые вопросы

**Где создаётся наряд (WorkOrder)?**
Автоматически при передаче заказа в цех (кнопка «Передать в цех»).

**Что делать если позицию невозможно изготовить?**
Тех.отдел ставит флаг «−» по позиции. Заказ переходит в статус «Невозможно изготовить». Требуется решение Зам.Тех.Дир.

**Как добавить материал в позицию?**
В детальной панели, при проверке тех.отделом — указать материал в поле позиции.

**Можно ли удалить заказ?**
Да — перетащите в колонку и нажмите «−» или смените статус на «Отменён».

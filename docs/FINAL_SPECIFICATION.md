# ATPP System — Финальная спецификация к выпуску

Версия: **v13**. Дата: **2026-05-14**. Статус: **готов к релизу**.

---

## 1. Назначение системы

Автоматизация технологической подготовки производства (ТПП) на предприятии
УЗГА-Инжиниринг. Система заменяет ручной труд технолога по проектированию
техпроцессов, расчёту норм, генерации документации и управлению производством.

# ГОСТ → ISO — таблица соответствия стандартов

ATPP изначально построен на ГОСТ 3.1xxx (ЕСТД). Для международных
проектов приводим соответствие со стандартами ISO.

| ГОСТ | ISO | Описание |
|---|---|---|
| ГОСТ 3.1109-82 (МК) | ISO 6983 / DIN 66025 | Маршрутная карта |
| ГОСТ 3.1118-82 (ОК) | ISO 10791 | Операционная карта |
| ГОСТ 3.1123-82 (КЭ) | ISO 128-40 | Карта эскизов |
| ГОСТ 3.1122-82 (ВО) | ISO 13399 | Ведомость оснастки |
| ГОСТ 3.1127-82 (ВМ) | ISO 10303-238 | Ведомость материалов |
| ГОСТ 2.102-68 (СП) | ISO 10303-210 (STEP) | Спецификация / BOM |
| ГОСТ 27.002-89 | ISO 14224 | Надёжность / scrap tracking |

## Экспорт в ISO-формат

Для генерации ISO-совместимых документов используйте:

```bash
python -m modules.doc_generator --format iso <tp_id>
```

Поля документов автоматически маппятся:
- Обозначение → Part ID
- Наименование → Part Name
- Материал → Material Grade
- Тпз / Тшт → Setup Time / Cycle Time (minutes)

## Примечания

- STEP (ISO 10303) уже поддерживается через `modules/cad_import.py`
- Полный переход на ISO — v13+

# ATPP_System — Итоговая оценка готовности к сдаче

**Дата:** 19.05.2026
**Объём:** ~47 000 строк Python, 212 .py файлов, версия 10.0.0

---

## Общая оценка: 5.5 / 10

**Система функциональна, но имеет критический технический долг.** Код написан с помощью AI, содержит характерные AI-артефакты. Основные функции работают, но надёжность под нагрузкой не подтверждена.

---

## Топ-5 рисков при сдаче «как есть»

1. **Потеря или повреждение данных из-за частичных коммитов в БД.**
   Два модуля самостоятельно выполняют `session.commit()`, нарушая целостность транзакций. При сбое часть данных сохранится, часть — нет.

2. **Скрытые ошибки в продакшене.**
   268 блоков `except Exception` ловят и проглатывают ошибки. Оператор не узнает о сбое. Бэкап может молча не создаться, документ — молча не сгенерироваться.

3. **Нестабильность UI при реальной нагрузке.**
   126 UI-тестов падают. База данных блокируется из основного потока Qt, замораживая интерфейс при длительных операциях. Отправка форм без валидации ввода вызовет крэш.

4. **Веб-клиент не готов к эксплуатации.**
   Покрытие тестами API — 25-80%. JWT хранится в localStorage (XSS). WebSocket live-обновления не протестированы под нагрузкой.

5. **Часть функций — заглушки или неполные реализации.**
   Функция `launch()` имеет цикломатическую сложность 33. IoT-симулятор возвращает твёрдые значения. Цифровой двойник не подключён к реальным станкам.
